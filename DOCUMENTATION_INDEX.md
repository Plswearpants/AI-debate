# Documentation Index

The project keeps a small active documentation set.

## Active Docs

- `README.md` - overview and quick start
- `DEPLOYMENT_GUIDE.md` - setup and configuration
- `ARCHITECTURE.md` - system design and data flow
- `CITATION_QUALITY.md` - citation behavior and tuning
- `CHANGELOG.md` - recent changes

## Configuration Files

- `.env.example` - API keys template (secrets only)
- `config.yaml` - runtime configuration (models, debate, budget, generation)

## Useful Scripts

- `run_debate.py` - start a new debate
- `resume_debate.py` - resume from checkpoint
- `verify_model_config.py` - verify loaded model configuration
- `test_openrouter.py` - test model/API access

## Notes

- Extra markdown files are retained as historical deep dives.
- For day-to-day use, prefer the active docs list above.
